# ShopVyra Backend

Production-ready E-Commerce Backend built using Spring Boot, Spring Security, JWT Authentication, JPA/Hibernate and PostgreSQL.

## Tech Stack

- Java 21
- Spring Boot
- Spring Security
- JWT
- Hibernate / JPA
- PostgreSQL
- Maven

## Features

- Authentication & Authorization
- Role-Based Access Control
- Product Management
- Category Management
- Cart Management
- Seller Features
- Admin Features
